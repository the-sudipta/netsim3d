Put test images in this folder so they are easy to find in the file picker.

Works best:
  - one car filling most of the frame, side or three-quarter view
  - daylight, clean background
  - JPG or PNG, any size (it gets resized to 224x224)

Also interesting to try:
  - a bus, a tractor, a fire engine: the model knows about forty vehicle types
  - a close-up of a wheel: the answer panel tells you it only found a part
  - something that is not a vehicle at all, to see the model say so
